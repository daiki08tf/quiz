# 問トレ

ITパスポート／基本情報技術者／応用情報技術者／情報セキュリティマネジメントの4区分について、
ひたすら4択問題を出題し、回答するとすぐに解説を表示するブラウザアプリです。
ビルド不要の素の HTML / CSS / JavaScript のみで動作します。

## 使い方

`index.html` をブラウザで直接開くか、簡易サーバーで配信してください。

```bash
npx serve .
# または
python3 -m http.server 8000
```

トップ画面で区分を選ぶ（または「4区分すべてをミックスして解く」）と出題が始まります。

- 選択肢をクリック、またはキーボードの `1`〜`4` で回答
- 回答すると正誤と解説がすぐに表示されます
- 「次の問題へ」（または `Enter` / `Space`）で次の問題へ。プール内の問題を解き終えると、
  順番をシャッフルし直して出題を継続します（＝ひたすら解き続けられます）
- 画面上部の家アイコンでトップ画面に戻れます

## 構成

- `index.html` — 画面構造（ホーム画面／クイズ画面）
- `style.css` — ダークテーマのスタイル
- `data.js` — 問題データ（`QUESTION_DATA`）とカテゴリ情報（`CATEGORY_META`）
- `app.js` — 出題ロジック（シャッフル、採点、解説表示）

## 問題データについて

収録している問題は、各試験区分（ITパスポート／基本情報技術者／応用情報技術者／
情報セキュリティマネジメント）の出題傾向に沿って作成したオリジナル問題です
（各区分60問、計240問）。

問題を追加・入れ替えたい場合は `data.js` の `QUESTION_DATA` に、以下の形式でオブジェクトを
追加してください。

```js
{
  q: "問題文",
  choices: ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
  answer: 0, // 正解の選択肢のindex(0始まり)
  explain: "解説文",
}
```
